Viewer backup

The viewer stores imported game backups, history charts, and goals in a SQLite database on the server. Export downloads that database as a backup. Import restores it and replaces all current viewer data. This is not the same as importing a game save (.json).

To add a new game save snapshot, use Import game backup in the sidebar.
